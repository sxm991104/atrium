# atrium

**所有聊天平台的门，都开到这儿。**

v1.0.1

> 这个仓库是派活台的**「说话那一半」**。
>
> 另一半（在电脑上真跑命令、真改文件）在
> **[remote-dispatch](https://github.com/sxm991104/remote-dispatch)**。

---

## 它解决什么问题

**你在外面，想在飞书或钉钉里跟自己的电脑说句话，电脑就真去干。**

```
飞书 / 钉钉  ──►  atrium  ──►  remote-dispatch  ──►  电脑上真干活
   你说的话        听懂            动手
```

**atrium 管前半截：**
收消息 → 判断「这是闲聊还是派活」 → 派给引擎 → 跑完把结果和文件推回聊天窗口

**它不做的事：**
- 不跑命令、不改文件（那是 [remote-dispatch](https://github.com/sxm991104/remote-dispatch) 的事）
- 不存历史版本、不做版本回退（那也是那边的事）

**两个仓库松耦合，都能单独用。**

---

## 它替你挡着什么

**"让 AI 在我电脑上跑命令" 听着就危险。** 所以前台这层不是简单转发：

**它不是"听什么做什么"**
先有个模型判断这句是闲聊还是要派活。你说"今天天气怎么样"，它直接答，不碰电脑。

**危险操作走验证码**
删东西、改权限、放开联网 —— 不是问你"确定吗"，是**发码到你邮箱**。
聊天的那个窗口被人拿到也绕不过它。

**权限按窗口分**
每个任务能碰多大地方单独设。改大要码，改小直接生效。

**能临时免打扰，但要码换**
嫌烦可以关一段时间验证码 —— 也是发码到你邮箱换的。关多久由你说，到点自动恢复。

**切安全模式只能收紧不能放松**
在聊天里让它"保护严格点"可以；让它"关掉保护"不行 —— 那件事只能你自己在电脑上点。

**这些保护的执行在 [remote-dispatch](https://github.com/sxm991104/remote-dispatch)。**
atrium 负责在聊天这一侧把门看住，那边负责在电脑上把活看住。

## 一条命令装好

```bash
npm i -g yatou-paihuo
paihuo install
```

**atrium 会被一起装好**（在 `<你选的目录>/atrium`），Python 依赖也一并弄好。

装完双击 `启动派活台.bat`，在桌面端「通道」页填飞书或钉钉的凭据就行。

---

## 支持哪些平台

**现在接了这两个，都是官方接口：**

| 平台 | 怎么连 | 要公网 IP 吗 |
|---|---|---|
| **飞书** | 自建应用 + 长连接 | **不用** |
| **钉钉** | Stream 模式 | **不用** |

**两个都是主动往外连** —— 不用备案、不用开端口、不用把家里的电脑暴露到公网上。

**接平台那一段就在这个仓库里。** 加新平台只要在 `atrium/platforms/` 加一个文件，
主程序不用改 —— 细节见 [DEVELOPER.md](DEVELOPER.md)。

## 它替你说什么（推送长什么样）

**任务干完了，它主动报到：**

```
「登录页」做完了
  · 改了 src/login.tsx、src/login.css
  · 生成了 登录页说明.docx
```

**一次跑完好几个，就用表格横向对比。**
**产出文件会一起发回来** —— 海报、文档、表格，直接能在聊天里点开。

## 自己跑（不用一键装）

```bash
python -m atrium.cli init       # 生成配置 ~/.atrium/config.json
python -m atrium.cli test       # 测凭据能不能用
python -m atrium.cli run        # 启动
python -m atrium.cli status     # 看队列积压
```
